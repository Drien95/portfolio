Site personnel : ingénieur cybersécurité et données (CY Tech 2026).

- Compétences : tableau `SKILLS` (`[nom, précision, contexte]`, contexte `pro`, `lab`, `form` ou vide).
- Publié par GitHub Pages depuis la branche `main`.
